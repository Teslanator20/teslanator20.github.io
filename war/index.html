Snipes · Bloody Trail

A snipe is an ownership change of Bloody Trail, the territory both guilds fight hardest to hold. Each one is credited to the guild that took it. If Bloody Trail was lost and won back between two polls, the loss counts for “other / unknown” and the retake for the holder. Counting starts with the exact territory log: the API has no ownership history before that.
